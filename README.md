# NLP-Based Automatic Keyword and Keyphrase Extraction Using TF-IDF

## Project Description

This project is an NLP-based application that automatically extracts important keywords and keyphrases from text documents using the TF-IDF technique.

## Features

* Manual text input
* TXT, PDF and DOCX file upload
* Automatic keyword extraction
* TF-IDF relevance scores
* Keyword relevance bar chart
* Word cloud visualisation
* Download extracted results

## Technologies Used

* Python
* Streamlit
* NLTK
* Scikit-learn
* Pandas
* Matplotlib
* WordCloud

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

## Project Purpose

The main objective is to reduce manual effort in identifying important keywords from lengthy text documents using Natural Language Processing.
